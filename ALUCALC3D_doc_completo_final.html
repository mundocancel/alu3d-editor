ALUCALC-3D Professional Engine

Diseño, cálculo, visualización y documentación para ventanas y puertas de aluminio

1. Visión General

Nombre de la actualización: ALUCALC-3D Professional Engine v2.0

Objetivo: Transformar ALUCALC-3D de un visor web básico en una plataforma profesional de diseño, cálculo, visualización y preparación para fabricación de ventanas y puertas de aluminio, utilizando datos reales de la línea Euroalum / Indalum.

Resultado esperado:

  • Seleccionar perfiles reales del catálogo.
  • Calcular automáticamente cortes y dimensiones.
  • Ensamblar un modelo 3D verificable.
  • Generar documentación lista para producción.
  • Escalar fácilmente a nuevas series y configuraciones.

2. Alcance Funcional

✅ Incluido en esta actualización

  • Catálogo técnico real
  • Series Euroalum / Indalum: 2500, 2800, 3800, 3900, 4000, 4500
  • Perfiles estructurales, junquillos, mosquiteros, adaptadores de traslape
  • Herrajes y accesorios básicos

🧮 Motor de cálculo

  • Evaluación de fórmulas paramétricas
  • Cálculo de longitudes de corte
  • Cantidad de piezas
  • Tipo de corte: 45° / 90°
  • Cálculo de dimensiones de vidrio

🧊 Visualización 3D

  • Ensamble paramétrico
  • Cambio dinámico de dimensiones
  • Compatibilidad con mosquiteros y jaladeras
  • Materiales básicos de aluminio y vidrio

📄 Generación de documentos

  • Lista de cortes
  • Croquis técnico 2D
  • Cotización preliminar

🧩 Arquitectura extensible

  • Catálogos desacoplados del motor
  • Layouts reutilizables
  • Reglas por serie

3. Objetivos de Negocio

Problemas actuales

  • Uso de medidas genéricas.
  • Cálculos manuales propensos a error.
  • No existe relación entre el modelo 3D y la fabricación real.
  • Difícil agregar nuevas series.

Beneficios esperados

  • Reducción de errores de fabricación.
  • Menor desperdicio de aluminio y vidrio.
  • Cotizaciones más rápidas.
  • Visualización previa para el cliente.
  • Escalabilidad del sistema.

7. Motor de Cálculo

Entrada { "serie": "2500", "tipo": "corrediza_doble", "ancho": 2400, "alto": 1500 } Proceso - Cargar reglas de la serie. - Resolver variables H y V. - Evaluar expresiones matemáticas. - Generar lista de piezas. Salida { "piezas": [ { "clave": "1695", "descripcion": "RIEL DOBLE", "cantidad": 2, "longitud": 2400, "corte": "45°" } ] }

8. Ensamblador 3D

Tecnología: Three.js / WebGL / WebGPU

Capacidades

  • Crear marcos paramétricos.
  • Crear hojas corredizas.
  • Posicionar vidrios.
  • Insertar jaladeras.
  • Insertar mosquiteros.
  • Actualizar geometría en tiempo real.

API interna

const window3D = WindowBuilder.build({ serie: "2500", layout: "4hojas_corrediza", ancho: 3600, alto: 2200, mosquitero: true });

Flujo lineal de extremo a extremo, con retroalimentación visual desde la etapa de cálculo hasta la documentación lista para producción.

11. Requisitos No Funcionales

Rendimiento

  • Generación de cálculo < 200 ms.
  • Ensamble 3D < 1 s para configuraciones estándar.
  • Soporte para ventanas de hasta 6 paneles.

Calidad

  • Cobertura de pruebas del motor de cálculo > 90%.
  • Validación de fórmulas al cargar catálogos.
  • Detección de perfiles inexistentes.

Compatibilidad

  • Navegadores modernos: Chrome, Edge, Firefox y Safari.
  • Resoluciones de escritorio y tablet.

13. Criterios de Aceptación

Catálogo

  • El sistema carga perfiles desde archivos JSON externos.
  • Es posible agregar una nueva serie sin modificar el código fuente.

Cálculo

  • Una ventana Serie 2500 genera exactamente las piezas esperadas según el catálogo técnico.
  • Las longitudes calculadas coinciden con las fórmulas del fabricante.

Visualización

  • El modelo 3D cambia al modificar ancho o alto.
  • Las jaladeras aparecen en las hojas móviles.
  • El mosquitero puede activarse y desactivarse.

Documentos

  • Se genera una lista de cortes descargable.
  • Se genera un croquis técnico con cotas.
  • Se calcula una cotización con materiales y accesorios.

14. Riesgos y Mitigaciones

RiesgoImpactoMitigación
Fórmulas incorrectas en el catálogo Alto Validador automático + pruebas unitarias
Modelos 3D demasiado pesados Medio Uso de geometrías simplificadas y reutilización de meshes
Incompatibilidad entre series y layouts Alto Reglas de compatibilidad en systems/
Crecimiento desordenado del catálogo Medio Esquemas JSON versionados y documentación obligatoria

16. Resumen Ejecutivo

La actualización ALUCALC-3D Professional Engine v2.0 convierte el proyecto en una plataforma técnica integral para la industria de cancelería de aluminio. La incorporación de catálogos reales de Euroalum / Indalum, un motor paramétrico de cálculo, un ensamblador 3D inteligente y un generador de documentación de fabricación permite automatizar el flujo completo desde el diseño hasta la preparación para producción.

La arquitectura basada en catálogos + reglas + layouts garantiza que el sistema pueda crecer incorporando nuevas series, accesorios y configuraciones sin necesidad de reescribir el núcleo del software, estableciendo una base sólida para futuras capacidades CAD/CAM y de manufactura digital.
